为什么从 Fashion-MNIST 14×14 升级到 LeNet-5（28×28 MNIST）：
- v2 基线只验证了 streamed-stage MAC + 单层 + multilayer FC 路径（Fashion 14×14 通过 patch_unroller 的 14×14 直接喂到 stage_engine）
- LeNet-5 需要原生 CONV 调度（28×28→28×28 conv1、28×28→12×12 conv2、flatten→fc1→fc2→fc3 五层串流），是 V2.B 第一次端到端跑真实 CNN 拓扑
- 增加内容：fmap_sram_v2、patch_unroller_v2、flatten_reader_v2、conv_ctrl_v2、stage_engine 扩展、conv_mode_cfg / conv_cfg_* / conv_ctrl 寄存器组、ARM 侧 v2b_run_conv_layer 调度器、Python 侧 gen_convnet_golden.py 全栈生成
- ARM 固件路径：arm_main.c 调用 v2b_run_lenet5_demo()，按层依次发 START + tile-by-tile WAIT_WEIGHT_REQ → 写 weight → WEIGHT_READY 握手

Step 1：Python 黄金参考与 .pth 训练
- 脚本：python_multilayer/gen_convnet_golden.py --network lenet5
- 训练流程：先训练浮点 ConvNet (conv1+conv2+fc1+fc2+fc3) → 量化 conv1/conv2 (4-bit signed [-7, +7]) →
  冻结前端 + 在量化 spike stream 上训练 SNN-FC head（fc1 max_level=3，fc2/fc3 max_level=7）
- 结果存入：python_multilayer/checkpoints/lenet5.pth + lenet5_snn.pth
- Manifest：python_multilayer/results_conv/lenet5/lenet5_golden_manifest.json
  - quant_snn_test_accuracy = 0.9303（10000 张 MNIST test set，预测率 93.03%）
  - selected_accuracy = 1.0（10 个 class-first 样本全部预测正确，与 hardware 严格 byte-exact）
  - t_count = 10
  - max_signed_level = 7
  - 5 层：conv1 (8) / conv2 (16) / fc1 (7) / fc2 (7) / fc3 (3)
